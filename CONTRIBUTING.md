# Contributing

Contributions that improve Hong Kong DSE topic coverage, platform tone, safety wording, or output consistency are welcome.

## Pull requests

1. Fork the repository and create a focused branch.
2. Keep the skill brand-neutral and free of credentials or machine-specific paths.
3. Preserve the four required output sections.
4. Avoid unverifiable education claims and guaranteed-result language.
5. Validate the plugin manifest and skill before opening a pull request.

Please keep changes small and explain the user-facing improvement in the pull request description.
